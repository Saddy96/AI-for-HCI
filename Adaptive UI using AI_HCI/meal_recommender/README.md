# Personalized Meal Recommendation System

## AI-Based Adaptive Human-Computer Interaction Project

### Course
Artificial Intelligence for Human-Computer Interaction

---

## Project Description

The Personalized Meal Recommendation System is an adaptive user interface application that learns from user behavior and recommends meals based on:

- Previous meals consumed
- Grocery shopping history
- Available ingredients
- User food preferences

The system dynamically changes recommendations as users record new meals and purchases.

---

# Features

## Meal Tracking

Users can record:

- Breakfast
- Lunch
- Dinner

The system stores historical eating patterns.

---

## Grocery Tracking

Users can record purchased items.

The application uses available ingredients when generating recommendations.

---

## Adaptive Recommendation Engine

The recommendation engine analyzes:

- Previous meals
- Recent meals
- Available ingredients
- User preferences

It ranks meals and provides explanations.
